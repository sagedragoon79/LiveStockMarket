# Live-Stock Market

A wool production chain for Farthest Frontier (v1.1.x Mono, MelonLoader 0.7 + HarmonyLib), built in steps. By SageDragoon.

Display name **Live-Stock Market**; namespace, DLL, and MelonPreferences category `LiveStockMarket`.

## Step 1 (current): Goats / Sheep mode on the goat barn

Adds a **Goats** / **Sheep** toggle to the info window of the vanilla goat barn, at both tiers (`GoatBarn` and `GoatBarn_Tier2` share the `GoatBarn` class). The mode is stored per barn and saved inside the normal save file. Default is Goats. A Sheep barn is named **Sheep Barn** (tier 2: **Large Sheep Barn**) in the window title, the map hover label, lists, and modals; the description blurb stays vanilla. Nothing else changes yet: a Sheep barn still runs vanilla goats.

Verified in-game on September 4, 2026: clicking flips the highlight, the mode survives save and reload, and it survives the tier 1 to tier 2 upgrade.

How it works (the author's building-work-modes pattern, ported from Warden of the Wilds):

| Piece | File | Notes |
|---|---|---|
| Mode store | `Systems/GoatBarnModeStore.cs` | Static dictionary keyed by rounded world position (`x*1000:z*1000`). Cleared on Map scene load, refilled by the Load postfix. `OnModeChanged` event refreshes the buttons. |
| Buttons | `Patches/GoatBarnModeButtonPatches.cs` | Postfix on `UIBuildingInfoWindow_New.SetTargetData`. The pair is overlaid on the barn portrait (`portraitImage`) at a normalized point inside the portrait rect. Position and size come from live preferences (see below). Fallbacks: a layout row above the vanilla livestock controls, then a fixed top-center overlay. |
| Persistence | `Patches/GoatBarnSaveLoadPatches.cs` | Postfixes on `LivestockBuilding.Save` / `Load`, filtered to `GoatBarn` instances only. Appends `int 'LSM1'` marker + `int mode` after vanilla's fields. Legacy saves (no marker) load as Goats. |
| Load-phase hook | `Patches/GoatBarnLoadPatches.cs` | Postfix on `LivestockBuilding.OnGameFinishedLoadingFinalize`. Step 1 re-applies the name and logs Sheep barns; later steps apply mode-driven data here. |
| Name | `Systems/GoatBarnNaming.cs`, `Patches/GoatBarnNamePatches.cs` | `Resource.displayName` is runtime-only (never saved, regenerated by `Building.SetBuildingDataRecordName`), and its setter feeds the map-label blackboard. The Sheep name ("Goat" replaced by "Sheep", or a " (Sheep)" suffix for other languages) is re-applied on click, in the Load postfix, and in a postfix on `SetBuildingDataRecordName`, which covers the tier upgrade. |
| Settings | `KeepClarityIntegration.cs` | `ModEnabled` master switch (restart required) plus the four button placement knobs. Registers with Keep Clarity's F10 panel when present. |

## Tuning the button placement in-game

The four **Buttons** preferences apply live. Open the barn window, press **F10**, open **Live-Stock Market**, and drag the sliders. Each change rebuilds the row on the open window. If a change doesn't show, click another building and then the barn again.

| Preference | Default | Meaning |
|---|---|---|
| `ButtonPosX` | 0.56 | Horizontal center of the pair across the portrait. 0 is the left edge, 1 the right edge. |
| `ButtonPosY` | 0.40 | Vertical center of the pair up the portrait. 0 is the bottom edge, 1 the top edge. |
| `ButtonWidth` | 95 | Width of each button in UI units. |
| `ButtonHeight` | 47 | Height of each button in UI units. |

The defaults are the values dialed in on September 4, 2026. The sliders stay in for now so the pair can be re-tuned if the portrait art changes in a later step; drop them before a release build.

## Build

```bash
dotnet msbuild -restore -p:Configuration=Debug LiveStockMarket.csproj
```

The csproj references the game DLLs by path under `C:\Program Files (x86)\Steam\steamapps\common\Farthest Frontier\Farthest Frontier (Mono)\`. After every build it makes a best-effort copy of the DLL into the game's `Mods/` folder (non-fatal if the file is locked).

## Deploy

MelonLoader 0.7 holds the loaded DLL open while the game runs, so a copy fails until the game exits. The watcher waits, then copies:

```bash
./deploy.sh
```

Pass `Release` to deploy the release build. New code takes effect on the next game launch.

## In-game checks for step 1

1. Launch the game and check `MelonLoader/Latest.log` for these lines:
   - `[LSM] GoatBarnSaveLoadPatches: patched LivestockBuilding.Save (mode persistence, GoatBarn only)` and the matching `.Load` line.
   - `[LSM] GoatBarnLoadPatches: patched LivestockBuilding.OnGameFinishedLoadingFinalize (load-phase mode hook)`.
   - `[LSM] GoatBarnModeButton: patched UIBuildingInfoWindow_New.SetTargetData`.
2. Select a goat barn. The portrait shows **Goats** (highlighted) and **Sheep** side by side. The log prints `GoatBarnModeButton: injected for 'GoatBarn #N' (mode=Goats, anchor=portrait x=0.56 y=0.40, size=95x47)`.
3. Click **Sheep**. The highlight moves, the title changes to **Sheep Barn** at once, and the log prints `Goat barn 'GoatBarn #N' mode → Sheep`. Hover the barn on the map: the label reads Sheep Barn too. Click **Goats**: the title returns to Goat Barn.
4. Save, quit to menu, load. The log prints `GoatBarnLoadPostfix: 'GoatBarn #N' restored mode=Sheep (name: Sheep Barn)` and `Load-finalize: 'GoatBarn #N' is in Sheep mode as 'Sheep Barn'`.
5. Upgrade a Sheep barn to tier 2. The new building is named **Large Sheep Barn** with Sheep still highlighted.
6. Load a save made before the mod was installed. Every goat barn shows Goats and the log shows no `[LSM]` warnings.

The `anchor=` value in the injection log line says which placement path ran.

## Known limitations (step 1)

- **Relocating a barn resets it to Goats.** Relocation destroys the old instance and builds a new one elsewhere, so the position key no longer matches. Warden of the Wilds solved this for the graveyard with `Relocate` / `ConstructionComplete` postfixes; port that once the mode drives behavior.
- **Uninstalling the mod** leaves 8 orphaned bytes at the end of each goat barn's tagged save data. Vanilla never reads them, but test a round-trip before shipping.
